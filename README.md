# Hospital Patient Care ETL Pipeline

## Overview
This project demonstrates an ETL (Extract, Transform, Load) workflow using a hospital patient care dataset. It is designed to organise and process healthcare-related data as part of a data pipeline assignment.

## Technologies Used
- Python
- Data processing and ETL concepts

## Project Structure
- `Hospital_Patient_Care_ETL/` — Contains the project files and ETL-related work.

## Key Steps
1. **Extract:** Read the source data.
2. **Transform:** Clean and prepare the data for analysis.
3. **Load:** Store the processed data in the required destination.

## Learning Outcomes
- Understanding the ETL workflow.
- Learning how data moves through a pipeline.
- Practising data organisation and processing.

## How to Use
Open the `Hospital_Patient_Care_ETL` folder to explore the project files and follow the instructions provided in the code or notebooks.
